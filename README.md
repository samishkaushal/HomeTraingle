# 🏠 HomeTraingle

A modern and responsive home services website built using **HTML, CSS, and JavaScript**. This project provides an easy way for users to explore and book various home maintenance and repair services.

## 🚀 Live Demo

🌐 **Vercel:**https://home-traingle.vercel.app/

🌐 **GitHub Pages:** https://samishkaushal.github.io/HomeTraingle/


## ✨ Features

- Modern & Responsive UI
- Home Services Categories
- User Login Page
- Contact Page
- About Us Page
- Privacy Policy
- Terms & Conditions
- Refund Policy
- Multiple Service Pages
- Mobile Friendly Design
- Clean Navigation
- Interactive JavaScript Components
